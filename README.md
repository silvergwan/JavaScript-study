# JavaScript Study

> javascript.info 기반 자바스크립트 핵심 개념 학습 저장소

## 구조
```
week01/   # 자바스크립트 기본 문법
week02/   # 함수 표현식, 콜백, 화살표 함수
week03/   # 클로저
```

## 학습 내용

| 주차 | 주제 |
|------|------|
| week01 | 변수, 자료형, 조건문, 반복문, 함수 기초 |
| week02 | 함수 표현식, 콜백, 화살표 함수 |
| week03 | 클로저 |

## 환경

- Node.js
- ESLint
